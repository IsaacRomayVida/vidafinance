# Fonts

Self-hosted variable fonts, served from this origin instead of Google Fonts
(faster first paint, no third-party request). `index.html` declares the
`@font-face` rules and preloads the two `latin` files.

| File | Family | Source |
|---|---|---|
| `urbanist-latin-wght-normal.woff2`, `urbanist-latin-ext-wght-normal.woff2` | Urbanist (wght 100–900) | `@fontsource-variable/urbanist` 5.3.0 |
| `doto-latin-wght-normal.woff2`, `doto-latin-ext-wght-normal.woff2` | Doto (wght 100–900) | `@fontsource-variable/doto` 5.3.0 |
